# 0.24 community preview

The Windows x64 portable and matching GPLv3 source archive are available locally:

- `release/preview-0.24.0/Polytope Laboratory 0.24.0 preview.exe`
- `release/Polytope Laboratory 0.24.0 source.zip`

This checkpoint adds environment-only refraction, bounded convex face/cell
distances, incidence truncation and quasitruncation, nonconvex 3D face nets,
4D whole-cell nets with ordinary convex/concave source cells, seven Stewart
toroids, sphere projection, tidy-dual faceting, moving source morph content,
generalized 3D sizing and searchable offline help. See
[development features and domains](RELEASE_0.24_DEVELOPMENT.md).

The actual portable passes with development Python unavailable. It loads the
catalog and genus-three Stewart assets, performs 3D/4D expansion, creates an
edge-defined tetrahedron and exact rational section, projects a tesseract onto
a sphere, unfolds a literal nonconvex 4D shell, quasitruncates a cube, evaluates
a regular-star sizing morph and displays four independent source views.

Source-app checks additionally cover refraction, bounded 4D cell distance,
quasitruncation adoption, concave face-net folding, sphere expression/default
controls, generalized whole-cell Save/Open, moving morph text/PNG capture,
enabled-morph persistence, unsupported image endpoint retention and F1/search
help. Detached camera initialization and billboard text orientation were fixed
during integration. Existing historical binaries and frozen stages are retained.

Receipts: `artifacts/community-preview-0.24.0.json`,
`artifacts/source-package-0.24.0.json`, `artifacts/source-pair-0.24.0.json`,
and `artifacts/preview-portable-quick-5UrGRU/result.json`.

This is a community preview. A full regression and measured 90% Stella4D parity
are not claimed. Broad catalog coverage and generalized construction domains
remain unfinished. Generalized expansion, automatic source symmetry and per-edge
tab controls are later staged work; they are not in this executable or its
corresponding source archive. No GitHub release has been published.
