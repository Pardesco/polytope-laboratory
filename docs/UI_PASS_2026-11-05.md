# UI pass — November 5, 2026 (proposal, pre-implementation)

Method: visible capture of 0.27.21 at 1600x1000 (monitor 2, `polytope-orchestra/steps/uipass.cjs`,
shots in `polytope-orchestra/shots/uipass/`), audited by Claude against the ui-ux-pro-max checklist
(accessibility, interaction, layout, typography, consistency), then reviewed by GPT Astra before any code.
The skill's generated "design system" targeted landing pages and was not used. We keep the existing dark
theme and fonts. This pass is about hierarchy, clarity and polish.

North star: someone who opens the app sees one beautiful shape, understands in ten seconds how to turn it
(including in 4D), and finds any tool without reading docs. Experts lose nothing.

## Findings (by severity)

### P0: visibly broken or misleading
1. **Model clipped by default.** In 4D perspective the tesseract runs off the bottom of the viewport (every
   capture). Fit doesn't account for the projected 4D extent or the overlays. The first impression is a cut-off shape.
2. **Two "projection" controls contradict each other.** The toolbar says `Perspective` (4D→3D projection) while
   View options says Camera `Parallel` (3D camera). Neither label says which dimension it means.
3. **Overlays collide on the canvas.** The "Shift-drag to turn in 4D" hint, the "Tip: Ctrl+K" bar, the stats strip and
   the shape itself all sit in the bottom 120 px of the canvas. The hint covers the shape's lowest vertex.
4. **Shape builder font bug.** The preview's body copy renders in monospace ("Drag the preview to explore…").
   The panel is also translucent enough that the Construct cards show through it.
5. **Guide search label overlaps its input border.**

### P1: hierarchy and clarity
6. **Top bar is a row of identical text buttons** (New Open Save | Undo Redo | Export | Guide | Search … Presentation,
   Full screen, Library, Inspector, ⋯). Panel toggles look like actions. There's no app identity, and Presentation appears
   twice (top bar + bottom dock).
7. **The Construct tool list uses the same cube icon on every card**, so icons carry no information. Tools that can't run
   on the current model ("Choose a 3D model for this tool") sit inline between usable ones. A 4D model shows about 6 dead cards first.
8. **Nets tab leads with unavailable options** for 4D models (Unfold faces, Paper model of visible surface are both "choose a 3D…").
   Jargon: "Edge 0 length".
9. **Advanced tab** opens with "FLOAT64 · APPROX" chips and two paragraphs saying calculations are numerical.
   The Analysis overview also says "Symmetry order 384 (numerical)". That's honest, but the wording reads as doubt.
   Say it once, plainly ("Computed numerically · checks passed") and keep the details for experts.
10. **Appearance dock popover** is an unaligned two-column form with raw numbers (`Vertex view radius 0.012`,
   `Edge view radius 0.0035`, `Cell 0`, `Fill rule: Nonzero winding`) in the default view. It covers the model.
11. **Library rail:** the "Link local OFF catalog" button permanently takes the primary footer slot. Collection cards
   clip mid-card inside a nested scroller. "Build from symmetry" is a plain button with no visual cue that it's a hero feature.
   The library count shows "39" during search with no label.
12. **Redundant chrome:** a "Model" label in the canvas corner; the stats strip duplicates the Analysis overview card.

### P2: polish and accessibility
13. Secondary text (~#8a94a6 at 11 px) is below 4.5:1 in places and too small. Body minimum should be 12–13 px.
14. Focus rings are inconsistent (some outline:none). Tab order should be checked on dock popovers.
15. Small hit targets: "?" help buttons and dock tabs are ~20 px tall (target ≥ 28 px for desktop pointer).
16. Guide body is walls of text. "What's new — October 26" is stale.
17. Respect `prefers-reduced-motion` for auto-rotation on start.

## Proposed packages (Codex Sol workers, after Astra review)

- **v1 Canvas first impression**: fit includes 4D perspective extent plus overlay safe areas (P0-1). One overlay
  zone (bottom-left stats, bottom-center single rotating hint that never covers the model, tips merged into it) (P0-3).
  Remove the "Model" label (P1-12).
- **v2 Projection clarity**: rename toolbar control to "4D view: Perspective/Parallel/…" and View options camera to
  "3D camera". Show the 4D control only for 4D models (P0-2).
- **v3 Top bar & identity**: grouped icon+label buttons (file / edit / make / view), a distinct segmented toggle for
  Library/Inspector panels, a small app mark, and one Presentation entry (P1-6).
- **v4 Construct & Nets relevance**: per-tool icons (inline SVG, one consistent 24px line set). Sort available tools first and
  collapse unavailable ones into "Needs a 3D model (6)". Same for Nets (P1-7, P1-8).
- **v5 Plain confidence**: unify numerical/exact wording; Advanced tab leads with a friendly summary (P1-9).
- **v6 Appearance popover**: aligned single-column form, sliders with human labels (Vertex size, Edge thickness),
  fill rule and cell isolation under Expert tools. The popover docks beside the canvas, not over the model (P1-10).
- **v7 Library rail polish**: Build-from-symmetry hero card, OFF linking moved to the ⋯ menu / Collections footer,
  collection grid without clipping, labeled result count (P1-11).
- **v8 Type, contrast, focus, targets** token pass in ui/style.css variables (P2-13..15) + shape-builder font and
  panel opacity (P0-4) + guide label (P0-5) + reduced motion (P2-17).

Each package: no capability or id removed; smokes keep finding ids; before/after visible screenshots.

## Astra review (gpt-6-astra, screenshots only) and what changed

Full text: `polytope-orchestra/reviews/astra_ui_review.md`. Adopted:
- **Mathematical names first, plain words second.** "Swap faces and corners" hides *Dual*. Cards lead with the
  real term (Dual, Truncate / Rectify, Stellate…) and use the plain sentence as the subtitle. Ctrl+K matches both
  vocabularies. (Reverses part of the 11-04 plain-language rule; the polytope community will look for the real names.)
- **Credibility wording:** "Save the exact geometry" overpromises → "Export model data" plus the precision it keeps.
  Known invariants (e.g. regular-polytope symmetry order) are labelled as known; numerically detected values as detected.
- **Composed opening:** framed model, one hint, and a dismissible "Explore this shape" strip with three actions
  (Turn in 4D · See its cells · Build a shape).
- **Task completion:** Nets leads with the applicable action ("Unfold this tesseract's cells") and its primary button stays visible.
- **Appearance docks beside a resized canvas**; Animation timeline redesign deferred to a later round.
- **Accessibility tokens first**: 14px body/control text, 12px minimum secondary, 18px panel titles, 36px standard
  controls / 32px utility targets, 8px grid, 16px panel padding, filled selected tabs, 2px focus outline.
- Header keeps readable labels (icons only alongside text).

Final package list (round 3): v1 canvas + projection clarity, v3 header, v4 tool vocabulary + relevance (Construct, Nets,
Ctrl+K), v5 credibility wording, v6 appearance dock, v7 library rail, v8 tokens/a11y/builder/guide, g1 geometry
correctness audit (community priority).
