## Lead fixes found only in the real app

- **Startup hang**: the construct gallery's MutationObserver and the disabled-reason explainer re-triggered each other forever
  (setting `disabled`/`title` to the same value still records a mutation). Both writers are now idempotent.
- **Engine allowlist**: `coxeter-build` (new) and `prepare-view-export` (since the October W16 package — Export → Displayed
  geometry was failing in the real app) were missing from `desktop/main.cjs`. New regression test
  `tests/engine-op-allowlist.test.cjs` checks every renderer `run('op')`.
- Library: typing a search inside a collection now searches the whole library; grid rows no longer collapse (`grid-auto-rows:max-content`).
- Sent back to workers after real-app review: dense "Open as model" (convex-import cap), dense hairball look, Learn 4D refusing to open during startup jobs / not refitting, monochrome single-type models.

## Randall's follow-ups (same day)

- **Dramatic 4D perspective**: new 4D views use eye distance 1.5 (was 3, which looked nearly orthographic); a **Depth** slider
  beside the projection picker maps 0–100 to eye distance 4 → 1.15 (log scale) and refits on release. Saved projects keep their distance.
- **Tumble**: a Shift-drag released while moving keeps turning at that speed (capped 90°/s) until Esc, a still Shift-click,
  Straighten, Shift-wheel or another rotation source; plain drags still orbit the 3D camera while it tumbles.
- Visible-window check (monitor 2, unfocused): Welcome and library thumbnails render; fixed a hover-identification
  "Illegal invocation" error that only occurs in a visible window.

## Smoke maintenance

The simplified UI hides many controls behind panes/popovers/expert groups. `scripts/smoke-helpers.cjs` now exports
`autoReveal(page)` (wired into all 87 Electron scripts): locator actions on a hidden target first run the shared `reveal()`.
Contract updates (documented in each script): Shift-drag is camera-relative (DIRECT_4D.md), construct tools are reached
through gallery cards, raw refusal text lives in friendly-error Details.
