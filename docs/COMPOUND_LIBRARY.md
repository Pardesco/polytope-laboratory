# Compounds and Add Dual

Construct → Modify this model → **Add Dual** (`add-dual`) adds a separately
owned polar component to the current source. Undo/Redo, saved project snapshots,
recipe replay and parameter branches use the existing native history workflow.
`add-dual-options` is collapsed; `add-dual-sizing` chooses automatic contact or
explicit reciprocation. Explicit sizing reads `incidence-dual-center` and
`incidence-dual-radius` under **Dual center and radius**, through NumericEntry.
Blank explicit center uses the existing dual operation's vertex-mean default.

In 3D automatic sizing fits the circumcenter, then checks a common sphere through
every edge midpoint, perpendicular to each edge. The polar about this center has
radius parameter ρ, so its vertices are `center + ρ² normal / facetDistance`.
Every corresponding dual edge must contain the primal midpoint. This supports
translated, scaled and rotated regular sources and other sources passing these
conditions. A general edge-tangent sphere need not touch at midpoints; those
sources require explicit reciprocation, without a midpoint-contact claim.

In 4D the convention is a sphere **centered at the source vertex mean**, tangent
to each polygonal ridge's affine plane. Its perpendicular contact must lie in
the ridge and on the corresponding dual edge. The same reciprocal formula uses
ρ²; this is a 2-face/ridge sphere, not the 4D edge sphere. Tesseract coordinates
±1 give ρ=√2 and dual vertices ±2 on the coordinate axes. A primal/dual 24-cell
pair uses this convention and need not have equal circumradii.

Automatic sizing requires validated full-dimensional convex 3D/4D geometry.
Explicit sizing also offers the existing finite incidence dual for generalized
3D/4D sources, subject to that operation's closed-link and nonsingularity limits.
There is no automatic search for an alternative 4D ridge-sphere center.
Sphere, midpoint and crossing residuals are stored in `metadata.addDual`, with a
relative tolerance of 2e-7 times source coordinate span. Analysis shows **Components**,
**Dual sizing** and **Dual contact residual (source units)**. Results are float64
approximations, without algebraic certificates.

Primal source colors survive; otherwise blue is assigned. The dual is orange.
Each component retains disjoint incidence, source snapshots and extraction maps.
New Add Dual component IDs are deterministic for replay followed by component
editing. Existing **Compound component**, **Keep component**, **Delete component**
controls remain available. No spatial welding, blending or union volume is inferred.

## Built-in library

Choose **Compounds** in `library-family`, or search `search` by name, spelled-out
component count, UC number, or `components=5`. There are 36 generated entries:

- Stella octangula; both five-tetrahedron enantiomers; ten and six tetrahedra.
- Three, four and five cubes and octahedra; two and five icosahedra/dodecahedra.
- Two and five great dodecahedra, small stellated dodecahedra, great icosahedra.
- Two, five (both enantiomers), ten truncated tetrahedra; five truncated cubes,
  cuboctahedra, rhombicuboctahedra; two snub cubes and two snub dodecahedra.
- Cube/octahedron and dodecahedron/icosahedron contact-sized dual pairs; an ordered
  great-dodecahedron/small-stellated polar pair (explicit unit reciprocation).
- Tesseract/16-cell, dual 24-cells, five 24-cells in a 600-cell.

The 24 distinct UC indices are **3–6, 8–9, 12, 17, 46–57, 59, 62, 68–69**.
UC5 and UC55 each expose both enantiomers. Four cubes, three octahedra and the
dual-pair entries are not assigned uniform-compound indices.
The full 75-entry classification and continuous-angle families are not claimed.

Orientations use existing catalog seeds and finite octahedral/icosahedral group
orbits. The tetrahedral catalog seed is aligned to alternating cube vertices;
three-cube seeds rotate 45° around a coordinate axis, four-cube seeds 60° about
(1,1,1). Icosahedral actions come from the existing exhaustive verified symmetry
engine. Five-icosahedron/star orbits exchange two coordinate directions before
acting. Snub pairs use central inversion. Every constituent keeps its ordered
cycles and cell incidence. `metadata.compoundSymmetry` retains group scope and
constituent matrices; maximal symmetry is not claimed. “Generated by symmetry”
describes the construction, not an exact-number certificate.

Five 24-cells use left quaternion cosets of the 24 Hurwitz unit vertices inside
the 120 binary icosahedral unit vertices. Numerical multiplication closure is
checked, and the five disjoint vertex sets must partition the 600-cell vertices.
This supplies one chirality; the opposite quaternion-coset form is a follow-up.

Names/UC crosswalk: [Antiprism's uniform-compound reference](https://antiprism.com/examples/150_named_models/540_uniform_compounds/imagelist.html).
Cube orientations and dual relationships: [George Hart's constructions](https://georgehart.com/virtual-polyhedra/compound-cubes-info.html).
These references supply naming/construction context; meshes are generated locally.
