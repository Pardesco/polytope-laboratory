# 0.25 community preview

The Windows x64 portable and matching GPLv3 source archive are attached to the [GitHub prerelease](https://github.com/Pardesco/polytope-laboratory/releases/tag/v0.25.0):

- `release/preview-0.25.0/Polytope Laboratory 0.25.0 preview.exe`
- `release/Polytope Laboratory 0.25.0 source.zip`

This checkpoint adds generalized 3D/4D expansion morphs, literal 4D incidence
duals, exact full/proper source-symmetry faceting and integer regular source
choices, default/per-edge physical glue tabs, source-color paper batches, and
concave/toroidal folding through saved keyframes, tours and PNG/WebM export.
See [development features and domains](RELEASE_0.25_DEVELOPMENT.md).

The actual portable passes with development Python unavailable. Its bundled
engine loads 1,292 catalog records, reciprocates the full tesseract incidence,
discovers the exact tetrahedron rotations group, evaluates regular-star 3D and
generalized 4D expansion, and builds double 5mm tabs with separated source-color
paper pages. Existing sphere, Stewart, ordinary 4D cell-net, quasitruncation,
exact-section, sizing and independent-view checks also pass.

Source-app checks pass the new controls, GPU PNG capture, native Save/Open,
moving source-rank text and affine PNG sheets, selected paper-color batches,
tidy-dual faceting adoption, three folding PNG times and three decoded VP8 frames.
The portable check exercises packaged availability; it is not a full regression.

Saved cameras persist during folding/export. A camera framed only for the flat
net can clip a later pose; review the animation and adjust its framing before
export. Automatic fitting of the entire folding motion remains open. Four-face
coincident-edge assembly, complete generalized 4D cell sections, morph video
tracks, infinite/hemi reciprocals and large annotated packet limits remain
unfinished or explicitly diagnosed. Earlier binaries/source pairs are retained.

Receipts: `artifacts/community-preview-0.25.0.json`,
`artifacts/source-package-0.25.0.json`, `artifacts/source-pair-0.25.0.json`,
and `artifacts/preview-portable-quick-qxweFq/result.json`.

This is a community preview. Feature completeness, full regression and measured
90% Stella4D parity are not claimed. The GitHub release is labeled as a prerelease.

The repository runtime files match the archived source. GitHub publication changes only documentation; the [source-pair record](RELEASE_SOURCE_PAIR_0.25.json) retains the archive and binary hashes.
