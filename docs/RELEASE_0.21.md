# Polytope Laboratory 0.21

[Verified Windows portable](../release/Polytope%20Laboratory%200.21.0.exe),
131,830,707 bytes, unsigned. SHA-256:
`f69deb34be6c7856c575f05a3c61f9d3d74f1c5fe856f679c4ec3d0fb5b64077`.

Automatic faceting now provides bounded source-vertex candidate pools and
source-face searches, detached preview and explicit adoption. Adoption retains
source colors/units/notes and supports Undo/Redo/Replay/Branch and native Save/Open.
Per-vertex faceting diagrams and remaining policy modes are still in development.

Dense stereographic refinement retains more source parameter area under the same
resource limits. Shared face boundaries and analytic normals preserve smooth
shading. Actual packaged opaque/translucent, worker, picking and projection
checks pass. Unresolved pole/depth/resource patches remain diagnosed partial
previews and refuse complete capture; camera-complete clipping remains open.

Video export now encodes immutable sampled poses with explicit timestamps.
Actual decoded tour output matches all seven reference PNG poses and timestamps,
including both endpoints; single-model offscreen output passes independent
endpoint checks too. The last pose is held for one additional sample interval,
recorded separately from source-timeline duration. WebCodecs VP8 is required.
The old endpoint defect remains documented in retained 0.19/0.20 evidence.

The release also retains the intervening regular-4D numerical validation,
bounded spring relaxation and broader expression-entry improvements.

Validation: 4,117 native tests pass with one platform skip; 1,576 frontend tests
pass; all 43 packaged desktop suites pass against unchanged runtime files.
The actual outer portable passes with development Python disabled, its full
extracted runtime matching the candidate, and all 3,064 linked-source hashes
verified. Native compiled modules/resources and fresh frontend build reproduction
match qualified source. The exact candidate was copied to the release path,
preserving earlier releases. All 847 qualified inputs are frozen separately.

Full Stella parity remains incomplete: 2 of the original 73 requirements are
validated, 65 have partial implementations and 6 are unstarted. Catalog identity
and classification, mathematical mode coverage, diagrams, reinforcement parts,
formatted content and broader hardware/clean-machine qualification remain open.
Development-only diagrams, dual morphs, curved fills and element content are
excluded from this release's implementation claims. The original full goal
and specification remain unchanged.
