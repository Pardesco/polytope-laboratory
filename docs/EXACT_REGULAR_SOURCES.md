# Exact regular sources

The **Exact regular source** Library family offers named integer-coordinate
tetrahedron, cube and octahedron realizations. These are alternate sources of
existing solids. Their original GPLv3 constructions retain explicit outward
face cycles and rational coordinate/support tables.

Use these choices when automatic faceting needs the full exact source group.
Their full/proper group orders are 24/12, 48/24 and 48/24 respectively. The
existing regular generators and imported sources remain available. Exact group
discovery evaluates the actual supplied coordinates; rounded nominal regular
solids can have fewer exact symmetries.

Select the family or search `exact faceting source`, then choose a source.
In Automatic facets, select **Discover full source group** or **Discover
rotations only**, build the candidate pool, and use **Use source faces** for
a bounded regular-boundary search. Criterion selection, preview, adoption and
saved history use the existing faceting workflow.

The coordinates are fixed canonical model-unit realizations rather than
unit-edge normalizations. Arbitrary later transformations can change exact
arithmetic or symmetry. The source evidence proves integer metrics, regular
face cycles and the complete bounded convex support intersection. Display,
measurements and downstream constructions retain their approximate numeric
contracts.

Native source and adopted-result Save/Open, automatic group discovery and
history replay pass focused checks. The desktop check in
`artifacts/feature-0.25-quick-NuAPGG/result.json` passes actual catalog selection,
rotations-only tetrahedral tidy-dual search, adoption and GPU capture.
